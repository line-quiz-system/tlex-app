# TLEX 学習アプリ - 経静脈的リード抜去術

経静脈的リード抜去術（TLE：Transvenous Lead Extraction）の全ガイドラインおよび臨床調査資料から作成された、臨床工学技士・循環器医療従事者向けのアクティブリコール（自力想起）＆忘却曲線学習アプリです。

目に優しく長時間学習しても疲れにくい「薄い黄色（ソフトクリーム＆アンバー）」をやわらかい基調とし、スマートフォンでの快適な片手操作と、好きな問題数での学習・いつでも中断できる自由な設計で構築されています。

---

## 主な特徴と機能

### 1. 15問の縛りをなくした自由な出題数と、いつでも中断・保存できる安心設計
- 5問、10問、15問、30問、あるいは中断するまで連続して解ける「全問連続」から好きな問題数をワンタップで選択可能
- 学習中の画面左上に「終了して戻る」ボタンを常時配置
- 1問解くごとにローカルストレージへ即時保存されるため、電車を降りる時やすきま時間の学習でも、解いた分の成果が一切失われません
- 中断時にはその時点での解答結果（覚えている/やや曖昧/忘れていた）をグラフィカルに集計表示
- ホーム画面に「前回の続きから再開」バナーが表示され、いつでも途中から再開可能

### 2. 薄い黄色（ソフトクリーム＆アンバー）のやわらかなデザイン
- 白や青の強い発色による目の疲労を抑え、やわらかなクリームイエローとアンバーをベースにした落ち着いた医療用デザイン
- ナイトモード（ダークモード）切り替えにも対応し、夜間の当直中や暗い環境でも快適に学習可能

### 3. 厳格な自力想起（アクティブリコール）訓練
- 選択肢に頼らず、問題文から自力で病態機序、具体的数値（308nm、80Hz、90%低減、30日死亡率7倍など）、ガイドライン推奨度を思い出す1問1答形式
- 模範解答・解説は150〜200文字程度で論理的に凝縮

### 4. 忘却曲線（SM-2アルゴリズム）による復習管理
- 「忘れていた（明日復習）」「やや曖昧（3日後復習）」「覚えている（7日後/14日後復習）」の3段階自己評価
- 復習期日が到来した問題をダッシュボードに自動集計して「本日復習」として提示

### 5. スマートフォン完全対応（オフライン・PWA動作）
- 完全スタンドアロン型: ネット接続のない地下鉄や院内でも動作
- 自動保存: 学習進捗はスマートフォンのローカルストレージに完全自動保存
- PWA対応: ホーム画面に追加することで、ブラウザ枠のない全画面ネイティブアプリとして起動

### 6. 問題庫・全文検索 & 統計分析
- 全75問をキーワード、カテゴリ、習得状態でリアルタイム検索
- 単問ごとの直接演習モーダル
- 単元別の習得率、定着済み問題数のグラフ可視化

## 収録問題（全75問）

1. 適応疾患とガイドライン基準（19問）
- TLEの基本定義、感染性適応の原則、ポケット感染/びらん/心内膜炎、非感染性適応、リコールリード（Sprint Fidelis / Riata）、三尖弁治療（TTVR/T-TEER）とJailed lead、推奨クラス（I/IIa/IIb/III）、抜去 vs 遺残（Abandonment）、MRI安全性のパラダイムシフトなど

2. 抜去手技フローとデバイス特性（18問）
- 術前画像評価（TEE・造影CT）、ロッキングスタイレットとスノープラウ現象、牽引とカウンター牽引、エキシマレーザーシース（GlideLight等）の機序とSVC損傷リスク、回転式機械的シース（Evolution RL, TightRail等）の特長、ハイブリッド戦略、大腿静脈アプローチ（スネア・タンデム）、術後管理など

3. 合併症・安全管理とハートチーム（17問）
- 二大致死的合併症（SVC損傷・心破裂）、ハイブリッド手術室の必須性、Bridgeオクリュージョンバルーンの機序と救命効果（生存率56.4%→91.7%）、PCPS（ECMO）スタンバイ、日本国内施設・医師基準（JHRSステートメント）、ハートチーム連携、SAFeTY-TLEリスクスコア、J-LEXレジストリ成績など

4. 最新知見・ペーシング技術と臨床判断（21問）
- 刺激伝導系ペーシング（CSP：HBP/LBBAP）とModel 3830ルーメンレスリード抜去の最新知見、不要リード放置から予防的抜去へのパラダイムシフト、施設ボリューム効果（ELECTRa）、J-LEX IIの最新展望、リードレスペースメーカ再植込み、高齢者フレイル評価など

## スマートフォンで学習する方法

### 方法1: index.htmlをスマホに送信して開く（一番簡単）
1. 本フォルダにある index.html をAirDrop、LINE（自分宛トーク）、Googleドライブ、iCloud、またはメール添付等でスマートフォンに送信します。
2. スマートフォンのブラウザ（SafariやChrome）でファイルを開きます。
3. これだけで即座に学習が開始できます。ネット接続が切れてもオフラインで動作し、学習データはスマホ内に自動保存されます。

### 方法2: スマホのホーム画面に追加してアプリ化する（推奨）
- iPhone (Safari):
  1. index.html をSafariで開きます。
  2. 画面下部中央の「共有」アイコン（四角から上向き矢印）をタップします。
  3. メニューから「ホーム画面に追加」を選択します。
  4. ホーム画面にやわらかな黄色のTLEX専用アイコンが配置され、タップすると全画面アプリとして起動します。
- Android (Chrome):
  1. index.html をChromeで開きます。
  2. 右上のメニュー（3点リーダー）をタップします。
  3. 「ホーム画面に追加」または「アプリをインストール」を選択します。

### 方法3: GitHub Pages などの無料ホスティングでURL化する
本フォルダのファイルをGitHubのリポジトリにアップロードし、Settings > Pages で「Deploy from a branch」を有効にすると、専用のWebアドレス（https://ユーザー名.github.io/リポジトリ名/）が発行され、外出先のどのスマートフォンからでもURLをブックマークするだけで使えます。
